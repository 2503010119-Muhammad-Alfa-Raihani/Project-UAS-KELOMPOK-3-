# Project-UAS-KELOMPOK-3-

Deskripsi proyek
Sistem perpustaakan modern adalah program sederahana yang dibuat menggunakan bahasaa pemograman C++ untuk membantu pengelolaan perpustakaan.
Program ini dapat digunakan untuk menyimpan data buku, melakukan peminjaman berbagai jenis buku, dan juga pengembalian buku, mencari buku,
serta memberikan rekomendasi buku kepada anggota.

Sistem ini bertujuan untuk membuat pengelolaan perpustakaan menjadi lebhih mudah, cepat, dan lebih terorganisir dibandingkan dengan pencatatan manual.

LATAR BELAKANG.

Dipepustakaan terdapat banyak buku yang harus di kelola dengan baik. Jika semua data dicatat manual, maka dapat terjadi kesalahan dalam hal tersebut, semisalnya kehilangan data, atau kesulitan saat mencari informasi buku.
Oleh karena itu, diperlukan sebuah sistem yang dapat membantu petugas perpustakaan dalam mengelola data buku dan transaksi pemeinjaman yang lebih efisien.
